Yondashuv 1 — Hash Map O(n)

Har bir element uchun target - nums[i] farqini hash mapda qidiring.

Bu O(n) vaqt va O(n) xotira talab qiladi.

C++ yechimi
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int,int> mp;
    for(int i=0; i<nums.size(); i++) {
        if(mp.count(target - nums[i]))
            return {mp[target-nums[i]], i};
        mp[nums[i]] = i;
    }
    return {};
}
