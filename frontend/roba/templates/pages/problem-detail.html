#Array

Berilgan butun sonlar massivi nums va butun son target. Massivdagi ikkita sonning yig'indisi target ga teng bo'ladigan indekslarini qaytaring.

Har bir kirishda aynan bitta yechim bor deb taxmin qilishingiz mumkin va siz bir xil elementni ikki marta ishlata olmaysiz.

Javobni istalgan tartibda qaytarishingiz mumkin.

Example 1:

Input: nums = [2,7,11,15], target = 9
        Output: [0,1]
        Explanation: 2 + 7 = 9, shuning uchun [0,1] qaytaramiz.

Example 2:

Input: nums = [3,2,4], target = 6
        Output: [1,2]

Example 3:

Input: nums = [3,3], target = 6
        Output: [0,1]

Cheklovlar:

  • $2 \leq nums.length \leq 10^4$
  • $-10^9 \leq nums[i] \leq 10^9$
  • $-10^9 \leq target \leq 10^9$

def two_sum(nums, target):
        seen = {}
        for i, num in enumerate(nums):
            complement = target - num
            if complement in seen:
                return [seen[complement], i]
            seen[num] = i
        return []
